# SIWC bridge in public Alpha

This snapshot includes II PRO's own bridge sources, JSON contract, build files and the original runtime integrity manifest. The third-party OpenAI transport and its compiled files are absent. Installing npm dependencies alone does not make the bridge usable. Runtime verification fails closed when any inventoried file is absent and Studio has no legacy transport fallback.
