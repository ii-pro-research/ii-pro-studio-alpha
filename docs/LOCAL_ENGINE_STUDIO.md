# Рабочее пространство инженеров Studio

Откройте PowerShell в корне рабочей копии и запустите Studio существующим Python 3.12 из окружения проекта. Собранный интерфейс уже включён в репозиторий.

```powershell
.\.venv\Scripts\python.exe -m ii_pro_ui
```

Откроется локальная вкладка Studio. Выберите «Задачи команды». Режим **Local** показывает зарегистрированные проекты, историю и инженерную память. **GPT** открывает существующие инструменты GPT Text и демонстрационные задачи команды. **Team** показывает готовность к совместной работе и пакет передачи из выбранной задачи Local.

Для регистрации проектов сохраните JSON-файл вне публичной папки сайта. Например, для уже подготовленного тестового проекта:

```json
[
  {
    "id": "pricing",
    "title": "Проверка скидки",
    "root": "C:/path/to/isolated-pricing-copy",
    "base": "<full git commit of the isolated copy>",
    "revision": "<full git commit of the isolated copy>",
    "files": ["pricing.py"]
  }
]
```

```powershell
.\.venv\Scripts\python.exe -m ii_pro_ui --local-projects .local\projects.json
```

Список доступен для подготовки задач. Для реального согласованного использования добавьте `--local-agent-live` при запуске Studio. Кнопка «Разрешить один шаг» применяет конкретный Core Approval и запускает одну генерацию. Следующий шаг готовится отдельно. При запуске другой сессии Studio повторно проверьте ещё не использованное разрешение. «Остановить дальнейшие шаги» сохраняет решение в журнале. Уже начатый запрос к Ollama может завершиться самостоятельно.

`--state-dir` выбирает один каталог общей базы Studio. Для пробной работы укажите отдельный каталог. История привязана к нему, а возобновление задачи требует исходного зарегистрированного снимка. При открытии базы её владелец по-прежнему один. При необходимости локальный оператор может указать `--import-mentor-memory <каталог-комплекта>`. Импорт проверяет комплект mentor-repair и сохраняет статус `tested`. Экран памяти доступен только для просмотра.

Пакет передачи версии 1 содержит исходную задачу, критерии, проект и снимок, файлы, допустимые инструменты и доказательства. Он предназначен для дальнейшего согласования в GPT Engineer. Team показывает статус и журнал согласованных операций. В публичном Alpha облачный транспорт SIWC недоступен.
