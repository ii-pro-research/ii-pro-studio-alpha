# M.1 — Continuity Engine 0.1

## Перенос

В Studio откройте «Настройки» и нажмите «Создать пакет для нового чата». Системный диалог позволяет выбрать папку и имя. Если браузер не предоставляет диалог, пакет поступит в обычные загрузки браузера. Полный путь из браузера недоступен. Studio показывает имя файла, время, этап, HEAD и результат проверки. Папка и имя не передаются локальному API.

Для работы без браузера используйте `python -m ii_pro_ui.continuity --state-dir PATH --directory PATH`. Команда создаёт `II_PRO_CONTINUE.zip` и сообщает его точный путь. Проверка без распаковки: `python -m ii_pro_ui.continuity --verify PATH`. Для продолжения работы передайте архив новому чату и попросите начать с `START_HERE.md`.

Ручное дополнение доступно через текстовый файл `.local/continuity/chat.txt` и явный параметр `--include-transcript`. Поместите туда только проверенный фрагмент своей переписки без конфиденциальных данных. По умолчанию браузер и CLI не включают этот файл. В манифесте он отмечен `manual_unverified`. Автоматического сбора истории чата нет.

## Содержимое и границы

Пакет версии 1 содержит выбранные документы из зафиксированного HEAD, сведения Git, проекцию статусов и доказательств из Core и короткий промпт. Рабочие изменения отмечаются флагом Git. Экспорт не копирует полную базу, историю браузера, источники приложений, секреты, действующие разрешения или хранилище авторизации. Срез Core ограничен 50 незавершёнными Run и пятью последними автономными испытаниями. В Core остаётся полный журнал. Прочие чаты не реконструируются. SHA-256 обеспечивает проверку целостности, авторство файла и полноту утверждений нужно устанавливать отдельно.

Последний завершённый инженерный этап L.6.4c подтвердил реальный цикл за 156,60 с после одного согласования. Три облачных запроса, один Local и один table_check, одно применение, один Worker и 11/11 сценариев. Итоговый кандидат на 4055 символов принят с первой подачи. Прежний кандидат на 4102 символа остался отклонённым. Автономная коррекция по размеру подтверждена Mock. Материалы обучения имеют статус unreviewed. Следующий инженерный этап не согласован.

При переносе исторический unknown остаётся запретом на повтор. Действующие полномочия выдаёт только Core. Проверка архива не создаёт задач, записей памяти, разрешений и не запускает программы или модели.

## Проверки

Целевые проверки и регрессия Studio и Core: 73 Python-теста прошли, один пропуск из-за отсутствующей локальной экзаменационной фикстуры. 96 UI-тестов и production-сборка прошли. Проверены доступ к HTTP только из локальной сессии, исключение тестового секрета и служебных полей, запрет ссылки на файл вне каталога, обнаружение подмены, усечённого архива и ZIP-записи с выходом за пределы пакета. Тестовый пакет читается без доступа к базе и репозиторию. Ruff E4/E7/E9/F прошёл.
