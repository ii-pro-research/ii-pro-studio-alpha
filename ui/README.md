# II PRO Studio Alpha

Запуск из корня снимка описан в [README](../README.md). Команда `python -m ii_pro_ui --no-docker-probe` открывает Studio на `127.0.0.1`. Не передавайте ссылку с ключом сессии. Закрытие вкладки оставляет сервер запущенным. Для завершения нажмите Ctrl+C в терминале.

Готовая сборка расположена в `ii_pro_ui/static`. Для её просмотра Node.js не требуется. Для разработки используйте Node.js 24.22.2 и закреплённый lockfile. Из папки `ui` запустите:

```sh
npm ci --ignore-scripts
npm test
npm run build
```

Сборка Vite заменяет только `ii_pro_ui/static`. Для публичного снимка облачный DevKit исключён. Для командных задач, School и других режимов проверяйте состояние и разрешения в Studio. Операционные требования указаны в [инструкции Local Engine](../docs/LOCAL_ENGINE_STUDIO.md).
